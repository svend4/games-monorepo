# Crystal Collector — прототипы рендера

Небольшая игра-демо: ходишь по арене, собираешь кристаллы, открывается портал.
Сделана для проверки разных техник рендеринга.

Это **отдельный проект**, не связанный с NEXUS (другой автор/время): интерфейс на английском,
встроена телеметрия самопроверки рендера `window.__renderCheck` / `document.body.dataset.renderCheck`.

| Версия | Папка | Технология |
|--------|-------|-----------|
| 2.5D | `v2-isometric-2.5d/` | Canvas 2D, изометрическая проекция, self-test `kind:'2.5d-canvas'` |
| 3D | `v3-3d/` | Three.js 0.165 (ESM через unpkg CDN), уровни в `data/level1..3.js`, `kind:'three-webgl'` |

Обе версии самодостаточны. Для v3 нужен интернет (Three.js грузится с CDN `unpkg.com`);
уровни переключаются параметром `?level=N`.
