# NEXUS — браузерная экшен-RPG

Одна игра в трёх версиях рендеринга, сделанных в разное время. Версии независимы — каждая в своей папке.

| Версия | Папка | Технология | Мультиплеер | Зависимости |
|--------|-------|-----------|-------------|-------------|
| **v1** | `v1-2d-mmo/` | Canvas 2D (вид сверху) | Да — PHP + MySQL | `nexus_api.php`, `nexus_setup.sql` (рядом, в той же папке) |
| **v2** | `v2-isometric/` | Canvas 2D (изометрия) | Нет | самодостаточна |
| **v3** | `v3-3d/` | Three.js r128 (WebGL) | Нет | модули из `shared/` + Three.js с CDN |

## `shared/` — общий движок

Модули `engine/ systems/ world/ ui/` — извлечение «Фаза 1» из `ARCHITECTURE.md`.
Сейчас их подключает **только v3** через `<script src="../shared/...">`. Стиль — ES5, глобальные функции,
общение через глобальные переменные (`THREE`, `scene`, `PS`, `pg` и т.д.).

> Если позже захотите, чтобы v1/v2 тоже использовали `shared/` — это и есть план миграции из `ARCHITECTURE.md`.

## v1 (2D MMO) — настройка бэкенда

1. Запустить MySQL (XAMPP).
2. Импортировать `v1-2d-mmo/nexus_setup.sql` (создаёт БД `nexus_world` и таблицы).
3. Открыть `v1-2d-mmo/game.html` строго через `http://localhost/...` (не `file://` — нужен PHP).
   Клиент опрашивает `nexus_api.php` каждые ~800 мс; без сервера корректно уходит в офлайн.
