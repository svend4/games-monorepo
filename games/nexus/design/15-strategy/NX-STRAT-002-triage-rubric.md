# Триаж и интеграция результатов роёв

> «Подготовка почвы»: инструмент, которым я (или владелец) превращаю десятки документов роёв
> в **приоритизированный бэклог** и в выбор вертикального среза — без перепроверки каждой строки.

## TL;DR
Каждый документ роя оценивается по 5 осям, считается приоритет `WSJF = (Impact×Fit×Novelty)/Effort`,
далее раскладывается по 4 корзинам (🟢 взять / 🟡 доработать / 🔵 отложить / 🔴 парковка). Результат —
одна таблица-бэклог и список противоречий для разрешения.

## Краткое содержание
Рой даёт **широту** (много идей разной зрелости и качества). Чтобы это не осталось «красивой
свалкой», нужен дешёвый, повторяемый фильтр. Триаж работает по **шапкам метаданных** (они для
этого и введены в [Конституции](../00-meta/CONSTITUTION.md)) плюс беглое чтение тела — не построчно.

## Расширенное содержание (общее)

### Оси оценки (заполняются из шапки + беглого чтения)
| Ось | Шкала | Откуда |
|---|---|---|
| **Impact** — влияние на игру | 1–5 | тело / `improves` |
| **Fit** — соответствие видению/рамке | 1–5 | `relates_to`, [NX-STRAT-001] |
| **Novelty** — новизна | 1–5 | `innovation_score` |
| **Effort** — трудозатраты | S=1·M=2·L=3·XL=5 | `effort` |
| **Risk** — риск | low/med/high | `risk` |
| **Maturity** — готовность | idea/analyzed/prototyped | `maturity` |

### Формула приоритета
```
WSJF ≈ (Impact × Fit × Novelty) / Effort
```
Высокий WSJF + Risk≤med + Maturity≥analyzed → кандидат в ближний срез.

### Корзины триажа
- 🟢 **Взять сейчас** — высокий WSJF, низкий риск, ложится в срез [NX-STRAT-003].
- 🟡 **Доработать** — перспективно, но нужна спека/прототип/уточнение.
- 🔵 **Отложить (север)** — ценно, но для поздних фаз / north-star.
- 🔴 **Парковка** — вне рамки, дубль, слишком рискованно (не удалять — `status: superseded` или тег `parked`).

## Детали и частные случаи

### Шаблон строки бэклога (для INDEX/таблицы)
```
| ID | Тип | Impact | Fit | Nov | Eff | Risk | Mat | WSJF | Корзина | Заметка |
```

### Обнаружение противоречий и дублей
- Два документа предлагают несовместимое (напр. realtime vs эхо) → завести `NX-CMT` с разбором и решением.
- Дубли темы → оставить сильнейший, остальные `superseded_by`.
- Висячие ссылки (`relates_to` на несуществующий id) → создать заглушку или поправить.

### Гейт «идея → спека → код»
Документ идёт в код-рой ([будущая волна]) только если: 🟢-корзина, есть спека с псевдокодом
(`40-specs/`), определён владелец-эмиттер событий и контракт API, нет нерешённых противоречий.

## Предложения и варианты реализации
- Когда оба роя завершатся — прогнать все ~44 документа через эту рубрику, выдать таблицу-бэклог
  в [INDEX.md](../00-meta/INDEX.md) (отдельная секция «Триаж»).
- Топ-5 🟢 + выбранный столп ([NX-STRAT-001]) → состав первого вертикального среза.

## Риски, открытые вопросы
- Субъективность оценок — смягчается тем, что оси берутся из шапок, а не из вкуса.
- Соблазн «взять всё» — лимит: не более N=5–7 пунктов в срез.

## Комментарии
Это инструмент, а не вердикт: рубрика помогает решать быстро и повторяемо, финальное «да/нет» —
за владельцем по [NX-STRAT-001].
