# NEXUS · Дизайн-вики

Растущая база знаний по игре NEXUS: **много маленьких связанных документов** (как статьи
Википедии) + псевдокод. Развивается **от общего к частному**, главное сейчас — **доработать
концепцию** (технически и концептуально), а уже потом по этим заготовкам рой напишет код.

Исходные черновики: [`../ARCHITECTURE.md`](../ARCHITECTURE.md) и
[`../ARCHITECTURE_REVIEW.md`](../ARCHITECTURE_REVIEW.md) — используются как прототипы, не как истина.

## Как пользоваться
1. Правила и формат документов — [`00-meta/CONSTITUTION.md`](00-meta/CONSTITUTION.md).
2. Шаблон нового документа — [`00-meta/TEMPLATE.md`](00-meta/TEMPLATE.md).
3. Полный список документов и граф ссылок — [`00-meta/INDEX.md`](00-meta/INDEX.md).
4. Старт по смыслу — [`10-vision/NX-VIS-001`](10-vision/NX-VIS-001-vision-and-pillars.md).

## Карта папок
| Папка | Префикс ID | Что внутри |
|-------|-----------|-----------|
| `00-meta/` | `NX-META` | конституция, шаблон, индекс, глоссарий |
| `10-vision/` | `NX-VIS` | видение, столпы, философия (общее) |
| `20-innovation/` | `NX-INN` | концептуальные инновации, 1 идея = 1 файл |
| `30-systems/` | `NX-SYS` | технический дизайн систем |
| `40-specs/` | `NX-SPEC` | детальные спеки + псевдокод (частное) |
| `90-comments/` | `NX-CMT` | комментарии и комментарии-на-комментарии |
