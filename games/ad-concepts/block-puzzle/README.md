# BLOCK SURGE — книга проектной документации

**Рабочее название:** Block Surge (рус. подзаголовок «Прилив»)
**Жанр:** block-puzzle без таймера, hybrid-casual (ставка №1 по данным рынка 2026)
**Платформы:** iOS + Android | **Стек:** Phaser 3 + TypeScript + Capacitor

---

## Elevator pitch

Block Surge — классический block-puzzle «положи фигуру на сетку 8×8, собери линию» с мгновенно понятным ядром уровня Block Blast! ($127 млн ad-выручки за 5 месяцев 2026). Дифференциация — комбо-система «Прилив»: серии очисток заряжают шкалу и дают кристальную фигуру-бомбу, а ежедневные «Фигурные поля» нестандартной формы кормят LiveOps и UA-креативы. Монетизация — IAA-доминанта (70% реклама / 30% IAP на старте) с эволюцией в гибрид 60/40 по образцу Color Block Jam ($100 млн за первый год).

**Монетизация одной строкой:** interstitial (7/DAU) + 4 rewarded-плейсмента (1.8/DAU) + баннер, поверх — полка IAP $0.99–$99.99, Remove Ads $4.99, Season Pass $4.99 и подписка $7.99/мес; целевой blended ARPDAU $0.15.

**Аудитория одной строкой:** широкий казуал 25–55 (ядро 30–45, значимая доля 45+), сдвиг к женской аудитории, приоритет Tier-1 — США, Япония, Германия, Великобритания.

## Юнит-экономика (базовый сценарий)

> LTV90 ≈ **$1.10** при blended ARPDAU **$0.15** (D1/D7/D30 = 38/15/6%), CPI $0.90 → **ROAS D90 ≈ 122%**, окупаемость UA ~день 52. Полный расчёт и сценарии — [глава 09](09-analytics-kpi.md) §5.
