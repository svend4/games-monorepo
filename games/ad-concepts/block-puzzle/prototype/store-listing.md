# Block Surge — ASO-пакет для стор-сабмишна (Проход Д)

Готовый к подаче стор-листинг для App Store и Google Play. Опирается на
[01-concept.md](../01-concept.md) (питч/USP), [02-market.md](../02-market.md)
(позиционирование), [06-monetization.md](../06-monetization.md) (данные/приватность:
медиация, атрибуция, IAP) и [07-ux-ui-ftue.md](../07-ux-ui-ftue.md) §4 (локализация,
доступность). Всё — финальный текст без заглушек.

**Язык:** основной — **английский** (широкий казуал Tier-1: US/UK/CA/AU; ядро аудитории
25–55, [01](../01-concept.md) §4). Полная версия дублируется на **русский**. Полный набор
локализаций v1.0 (по [07](../07-ux-ui-ftue.md) §4): EN, JA, DE, FR, ES, PT-BR, KO, RU.
Ниже даны готовые EN + RU; остальные семь — по этому же шаблону через агентство локализации
([10](../10-production.md) §4).

**Лимиты полей (для проверки на подаче):** App Store — Name ≤30, Subtitle ≤30, Keywords ≤100,
Promotional Text ≤170, Description ≤4000. Google Play — Title ≤30, Short description ≤80,
Full description ≤4000. Все поля ниже уложены в лимиты (счётчик указан в скобках).

## 9. Privacy Nutrition — данные и приватность

Состав SDK и, значит, собираемых данных — из [06](../06-monetization.md) §8 (медиация/атрибуция/
аналитика) и [10](../10-production.md) §1 (стек). Регистрации/аккаунта нет (холодный старт без
логина, [07](../07-ux-ui-ftue.md) §3 шаг 1); идентификация — анонимный Firebase Auth. Имя, e-mail,
телефон, контакты, точная геолокация **не собираются**.

### 9.1 Что собирается и зачем (источник — SDK)

| Категория данных | Что именно | Зачем | Через что |
|------------------|-----------|-------|-----------|
| Идентификаторы | Рекламный ID (IDFA — по согласию ATT; GAID), анонимный app-instance ID, IP (обрабатывается, не хранится как профиль) | Показ и атрибуция рекламы, антифрод, частотные капы | AppLovin MAX + сети (AdMob, Mintegral, Unity, Liftoff), AppsFlyer/Adjust |
| Данные об использовании | События сессий, прогресс, взаимодействия с рекламой, impression-level ad revenue | Продуктовая аналитика, LTV-модель, A/B ([09](../09-analytics-kpi.md)) | Firebase Analytics, MAX impression API |
| Покупки | История IAP (без платёжных реквизитов — их держит стор) | Выдача товара, восстановление покупок, подписка | RevenueCat |
| Диагностика | Крэш-логи, производительность | Стабильность (крэш-фри ≥99.6%, [10](../10-production.md) §3 Проход Д) | Firebase Crashlytics |
| Приблизительная локация | Страна/регион из IP | Гео-таргет рекламы и eCPM, ценообразование стора ([06](../06-monetization.md) §6) | Ad SDK |

**Платёжные данные (карта, банк) приложение не видит** — их обрабатывает только стор (Apple/Google).

### 9.2 iOS App Privacy (карточка «Конфиденциальность приложения»)

- **Data Used to Track You** (используется для трекинга → требует ATT-разрешения):
  Identifiers (Device ID/IDFA), Usage Data, Product Interaction, Advertising Data,
  Coarse Location.
- **Data Not Linked to You** (не связывается с личностью — аккаунта нет):
  Identifiers, Usage Data, Diagnostics, Purchases, Coarse Location.
- **Data Linked to You:** отсутствует (нет учётной записи/личных данных).

### 9.3 Google Play Data safety

- Собирается: App activity, App info & performance, Device/other IDs, Purchase history,
  Approximate location. Все — «для рекламы/маркетинга, аналитики, предотвращения мошенничества,
  функциональности».
- **Data shared** с третьими лицами (рекламные сети/атрибуция): Device IDs, Approximate location,
  App activity — для показа рекламы. Задекларировано в форме Data safety.
- Шифрование при передаче — да (TLS). Запрос на удаление данных — поддерживается (deletion request).

### 9.4 Согласия и регуляторика

- **ATT (Apple):** перед включением IDFA-трекинга показываем системный App Tracking Transparency
  prompt (не в первую сессию до первой победы — [07](../07-ux-ui-ftue.md) §3; прайминг-экран поясняет
  выгоду). Отказ → только контекстная (non-personalized) реклама; opt-in по рынку ~27%
  ([02](../02-market.md) §1.1) — модель это учитывает.
- **GDPR/ePrivacy (EU/UK):** сертифицированный CMP с IAB TCF v2 через MAX; баннер согласия до
  инициализации рекламных SDK; отзыв согласия — из настроек. Правовая основа аналитики — согласие.
- **CCPA/CPRA (California) и US-state laws:** ссылка «Do Not Sell or Share My Personal Information»
  и Limit-опция в настройках приватности.
- **COPPA / возраст:** приложение **общей аудитории**, **не направлено на детей**, не в Kids-категории.
  Мы не собираем осознанно данные лиц младше 13 (US) / младше применимого возраста согласия (EU).
  Персонализированная реклама и IDFA-трекинг гейтятся ATT/CMP; при индикации «пользователь —
  ребёнок» персонализация и трекинг отключаются, показывается только контекстная реклама. Ссылки на
  Privacy Policy и Terms of Use — в листинге и в приложении (обязательны для стора).
