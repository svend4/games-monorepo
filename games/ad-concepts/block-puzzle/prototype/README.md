# Block Surge — прототип (Проходы А + Б)

Играбельное ядро по [главе 03](../03-core-gameplay.md) и [приложению 11](../11-algorithms.md) плюс слой экономики и мета-прогрессии по [главе 04](../04-meta-progression.md) и [главе 05](../05-economy.md). Без сборщиков и без внешних зависимостей — чистый Canvas 2D + DOM.

## Запуск

Любой статический сервер из каталога `games/ad-concepts`:

```
python -m http.server 8145 --bind 127.0.0.1 --directory games/ad-concepts
```

Открыть http://127.0.0.1:8145/block-puzzle/prototype/ (в проекте есть конфиг `.claude/launch.json` с этим сервером). Файл `index.html` работает и напрямую с `file://`.

## Управление

Перетаскивай фигуру из дока на поле 8×8: зелёный призрак — можно ставить, красный — нельзя, подсвечиваются линии, которые соберутся. Заполняй ряды и столбцы; серии очисток дают комбо ×2/×3/×5 и заряжают шкалу «Прилив». При полной шкале в четвёртое гнездо дока приходит кристальная бомба 3×3 — перетащи её на поле. Game over — когда ни одна фигура не помещается.

## Объём Прохода А

Реализовано: поле 8×8, bag-генератор с режиссёром сложности и проверкой размещаемости (SOLVENCY-CHECK), drag&drop мышью и тачем, одновременная очистка рядов/столбцов, счёт по таблице 03 §2.2, комбо-автомат, шкала «Прилив» и бомба, честный game over, рекорд в localStorage (`blocksurge_best`).

В проде стек меняется на TypeScript + Phaser 3 + Capacitor (см. [главу 10](../10-production.md)).

## Объём Прохода Б — экономика и мета-прогрессия

Слои добавлены поверх ядра, не переписывая core loop. Новый код — в отдельных модулях `economy.js` и `meta.js`, подключённых в `index.html` **перед** `game.js`; ядро вызывает их через несколько добавленных хук-функций (`window.Meta.onMove/onBomb/onGameEnd/onNewGame/snapshot`). Константы экономики (валюта, earn-rate, цены бустеров) вынесены в `ECON` наверху `economy.js` и согласованы с главой 05.

**Экономика монет (05 §1–2, §4).** Единственная валюта — монеты. Приход: за очистку линии `1 × множитель комбо` (05 §2.1), бонус за «чистое поле», и монеты за конец партии `floor(score/100)` (аналог «Победа на уровне 25–50»). Баланс — в HUD (верхняя панель) и в `localStorage`; стартовый баланс 200 (FTUE-подарок, 05 §3).

**Бустеры-инвентарь (05 §2.2, §5).** Три бустера с именами и ценами из главы 05: **Отмена** (80🪙, откат последнего хода), **Обмен** (120🪙, новая тройка фигур), **Молот** (150🪙, убрать одну клетку поля). Кнопки со счётчиком — в UI партии под полем; расходуются при использовании, докупаются за монеты (клик по пустому бустеру покупает, повторный — применяет). Влияние на партию — через глобалы ядра (`board`/`hand`/`dealHand`/`refreshPlaceable`).

**Карта «Путешествия» (04 §2).** Линейный трек из 12 узлов; прогресс — по суммарным ★ за партии (1/2/3★ по очкам). Узлы дают награды (монеты/бустеры), «босс»-узлы — усиленные. Открывается кнопкой «🗺️ Карта · магазин · миссии» с основного экрана.

**Стрик дней (04 §3).** Цикл 7 дней с нарастающей наградой (30→150🪙, день 7 + Молот). Для прототипа — кнопка «Получить награду дня» (доступна раз в календарный день) и «⏭ Новый день (тест)» для имитации смены суток; пропуск 2+ дней сбрасывает серию.

**Ежедневные миссии (04 §4.1).** 3 миссии в день с ротацией из пула (детерминированно по дате). Прогресс считается по событиям партии (очистки линий, комбо, «чистое поле», сыгранные партии, очки); все 3 закрыты → бонус-сундук 60🪙.

Мета-экран (карта + магазин бустеров + миссии + стрик) достижим из игры и обратно. Петля замкнута: партия → монеты/звёзды/прогресс миссий → мета → бустеры → влияют на партию.

Лёгкий трекер `window.Analytics` логирует ключевые события по дереву [09 §2.2](../09-analytics-kpi.md) (`currency_earn/spend`, `booster_used`, `mission_complete`, `streak_change`, `game_end`).

### Хранение и совместимость сейва

Проход А хранил один ключ `blocksurge_best` (рекорд, не тронут). Проход Б добавляет ключ `blocksurge_meta` (единый JSON: монеты, бустеры, ★, карта, стрик, миссии). Схема совместима: при отсутствии ключа или отдельных полей подставляются дефолты (глубокое слияние), поэтому старые сейвы Прохода А игру не ломают (проверено: сейв только с `blocksurge_best` грузится без ошибок, мета инициализируется дефолтами со стартовым балансом 200).

## Смоук-тест (пройден)

`node --check` чист на всех трёх JS-файлах (`economy.js`, `meta.js`, `game.js`). Живой прогон в браузере (Проход А): постановка фигур, очистка линии, комбо, спавн и взрыв бомбы, game over, рестарт, сохранение рекорда — без ошибок консоли. Проход Б: старт с 200🪙; покупка бустера (списание монет + счётчик); мета-экран (карта/магазин/миссии/стрик) рендерится и закрывается; клейм награды стрика (+монеты, смена дня); кнопка «Новый день» ротирует миссии и открывает награду; хуки геймплея (`onMove`/`onGameEnd`) начисляют монеты и ★, засчитывают миссии; бустеры Отмена/Обмен/Молот меняют состояние партии (откат хода, редил тройки, снятие клетки); всё сохраняется и переживает перезагрузку; старый сейв Прохода А совместим — без ошибок консоли.
