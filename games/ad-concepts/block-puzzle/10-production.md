## 1. Технологический стек

### 1.1 Основной вариант: веб-стек

**Phaser 3 + TypeScript + Capacitor (iOS/Android) + AppLovin MAX / AdMob через Capacitor-плагины.**

| Слой | Выбор | Обоснование |
|------|-------|-------------|
| Движок | Phaser 3 (арена: PixiJS + свой каркас) | Phaser даёт сцены, тайлы, твины, инпут из коробки — для 2D-сетки этого достаточно; PixiJS выбрали бы при жёстких требованиях к кастомному рендеру, у нас их нет |
| Язык | TypeScript strict | Контракты данных (уровни, конфиги, события аналитики) типизируются; критично для генераторов [03](03-core-gameplay.md) §4 |
| Обёртка | Capacitor 6 | Нативные сборки iOS/Android из одной кодовой базы; плагинная модель для SDK |
| Реклама | AppLovin MAX (официальный Cordova/Capacitor-плагин); fallback — @capacitor-community/admob | Решение по медиации — [06](06-monetization.md) §8; чек совместимости плагина — задача Прохода В с запасным путём |
| IAP | RevenueCat (Capacitor SDK) | Единая подписочная логика iOS/Android, серверная валидация чеков без своего бэкенда |
| Аналитика | Firebase + AppsFlyer (Capacitor-плагины) | [09](09-analytics-kpi.md) §1 |
| Remote config / A/B | Firebase Remote Config | Kill-switch и параметры [08](08-liveops.md) §8 |
| Бэкенд | Минимальный: Firebase (Auth anonymous, Firestore — лиги, community-цели, облачное сохранение) | Без своего сервера в v1.0 |
| Хранение прогресса | Локально (Preferences/SQLite) + облачный бэкап | Игра полностью играбельна офлайн; реклама офлайн не показывается — деградация принята |

### 1.2 Честное сравнение с Unity

| Критерий | Phaser+Capacitor | Unity | Вердикт |
|----------|------------------|-------|---------|
| Скорость прототипа 2D-сетки | Дни; горячая перезагрузка в браузере | Дни–недели; итерация медленнее | Web ✔ |
| Зрелость ad-SDK | Плагины Cordova/Capacitor: MAX и AdMob официальны, но менее обкатаны, риск версий | Первоклассная: MAX/LevelPlay/AdMob поддерживают Unity в первую очередь | Unity ✔ — главный риск веб-стека |
| Производительность | Для сетки 8×8 и твинов — с запасом (60 fps на устройствах 2018+) | Избыточна для задачи | Паритет для нашего жанра |
| Размер билда | ~15–25 МБ | 35–60 МБ | Web ✔ (CPI: меньше отвал на загрузке) |
| Команда/рынок труда | TS-разработчики дешевле и доступнее | Unity-сеньоры дороже | Web ✔ |
| Порт в playable ads и web | Почти бесплатно (тот же код) | Отдельная работа | Web ✔ — playable-креативы критичны для UA |
| Лицензии | MIT/бесплатно | Runtime fee/подписки | Web ✔ |
| 3D/будущие жанры | Нет | Да | Unity ✔ (для нас нерелевантно) |

**Решение:** веб-стек. Точка невозврата — конец Прохода В: если MAX-плагин не проходит чек-лист (показы всех форматов, impression-level revenue, стабильность на 20 устройствах), переходим на fallback AdMob-медиацию, а миграцию на MAX откладываем до нативного модуля. Полный переезд на Unity рассматривается только при провале обоих путей (вероятность оценивается как низкая).

## 2. Состав работ (WBS, верхний уровень)

1. **Ядро:** поле, генератор фигур с солвером, очистки, очки, Прилив, режимы (Путешествие/Классика/Поля), fail/continue.
2. **Контент-пайплайн:** генератор уровней + автоплей-бот-валидатор, редактор масок полей, CMS сезонов, remote config.
3. **Мета:** карта, звёзды/сундуки, стрик, миссии, лиги (Firestore), сезонный трек, скины.
4. **Экономика/магазин:** кошелёк, полка IAP (RevenueCat), копилка, Remove Ads, подписка.
5. **Реклама:** ad-контроллер (правила [06](06-monetization.md) §3, сегменты §7), интеграция MAX, баннер-лейаут.
6. **Аналитика:** событийный контракт, Firebase/AppsFlyer, BI-экспорт, дашборды KPI.
7. **UX/UI:** экраны [07](07-ux-ui-ftue.md), FTUE-скрипты, доступность, локализация 8 языков.
8. **LiveOps-операционка:** пуши, ивент-планировщик, календарь [08](08-liveops.md) §7.
9. **Платформенное:** сборки, сторы, ASO-пакет, privacy (ATT, GDPR/CCPA-консент), крэш-репортинг.

## 3. Роадмап проходами (от простого к сложному)

### Проход А — играбельное ядро (6 недель)

- **Скоуп:** WBS-1 без Полей: сетка, драг с офсетом 80 px, 14 фигур + солвер честности, очистки, очки, комбо+Прилив, Классика, 40 уровней Путешествия (ручные шаблоны), continue за монеты (заглушка кошелька), плейсхолдер-арт.
- **DoD:** медиана партии Классики 6–9 мин на плейтестах (n≥10 внешних игроков); 0 «нечестных» game over на 500 бот-партий; 60 fps на Moto G-класса; FTUE-скрипт шагов 1–9 проходит без подсказок вслух; сборки на устройствах через Capacitor.
- **Риск-фокус: kill-гипотеза №1** — «Прилив делает партию заметно интереснее»: опрос плейтестеров A (с Приливом) vs B (без) — если разницы нет, фича упрощается или заменяется до входа в Проход Б.

### Проход Б — мета и экономика (6 недель)

- **Скоуп:** WBS-2, 3, 4 (без подписки): кошелёк и все sources/sinks [05](05-economy.md), бустеры, карта+звёзды+сундуки, стрик, миссии, генератор уровней с ботом (главы 1–6, 120 уровней), Фигурные поля (10 масок), магазин с IAP (тест-режим), финальный арт-стиль «неон».
- **DoD:** симулятор экономики воспроизводит таблицу день 1–30 из [05](05-economy.md) §4 с отклонением ≤10%; уровни 1–120 проходят бот-валидацию в целевых fail-коридорах [03](03-core-gameplay.md) §5.2; IAP-сэндбокс-покупки проходят на обеих платформах; полный daily-цикл играется за ~20 мин.

### Проход В — монетизация и аналитика (6 недель)

- **Скоуп:** WBS-5, 6 + подписочная инфраструктура (выключена), пуши, консент-флоу (ATT/GDPR), все 3 формата рекламы + 4 RW-плейсмента + ad-контроллер правил, событийный контракт целиком, дашборды D1/D7/ARPDAU, ASO-пакет и стор-страницы.
- **DoD:** чек-лист MAX-плагина пройден (или активирован fallback AdMob — решение зафиксировано); каждый плейсмент отдаёт `ad_impression` с eCPM в BI; правила interstitial покрыты автотестами (9 правил [06](06-monetization.md) §3); событийная схема валидируется в CI; крэш-фри ≥99.5% на регрессе из 30 устройств.

### Проход Г — soft launch (10 недель)

- **Скоуп:** запуск в 2–4 странах (Филиппины/Индонезия — дешёвые установки для воронки; Канада/Австралия — Tier-1 прокси по монетизации); UA-бюджет $25–35k; итерации по данным: FTUE-воронка, кривая сложности, INT-тайминг (A/B №1), баланс экономики; 2 полных сезона контента в конвейере.
- **DoD = kill/scale-гейт [09](09-analytics-kpi.md) §5.4:** D1 ≥38%, D7 ≥15%, ad ARPDAU (T1-прокси) ≥$0.10, D7 ROAS ≥40% на когортах ≥5k установок. Ниже kill-порогов — остановка проекта с ретро; в коридоре iterate — +4–6 недель итераций (максимум два цикла).
- Организационно: недельный ритм LiveOps [08](08-liveops.md) §8 включается уже здесь — команда учится оперировать до global.

### Проход Д — global launch (4 недели + ongoing)

- **Скоуп:** фичеринг-питчи сторам, локализация 8 языков финализирована, подписка on (после чек-листа платежей), винбек-цепочки, масштабирование UA на США/Японию/Германию/UK, календарь сезонов на 6 месяцев, план A/B №2–10.
- **DoD запуска:** крэш-фри ≥99.6%; все KPI-дашборды и алерты живые; 2 сезона контента готовы + третий в конвейере; UA-структура кампаний по гео согласована с моделью CPI $0.90 blend.

**Итого до global: ~32 недели** (А 6 + Б 6 + В 6 + Г 10 + Д 4), при одном iterate-цикле в soft launch — до 38 недель.

## 6. Процессы

- Итерации: 2-недельные спринты; демо на устройствах каждый спринт.
- Ветвление: trunk-based, фичефлаги через remote config.
- Качество: CI (типы, тесты генераторов и ad-правил, валидация событийной схемы), device-ферма 10 устройств локально + облачная на регресс.
- Решения: ADR-записи в вики; изменения экономики — только синхронно в главах [05](05-economy.md)/[06](06-monetization.md)/[09](09-analytics-kpi.md) и конфиге.

## 7. Бюджет-прикидка (до global + 1 месяц, ~9 месяцев)

| Статья | Расчёт | Сумма |
|--------|--------|-------|
| Команда | ~$26k/мес суммарно на команду 5.0 FTE (EU-remote микс ставок, в среднем ~$5.2k/мес на FTE с учётом частичных ролей) × 9 мес | $234k |
| Аутсорс: аудио, локализация 8 языков, ASO | пакетно | $18k |
| Инструменты/сервисы (device-ферма, BI, RevenueCat, сторы) | ~$1.5k/мес | $14k |
| UA soft launch | Проход Г | $30k |
| UA global seed (месяц 1) | старт масштабирования | $50k |
| Резерв | 15% от суммы выше | $52k |
| **Итого** | | **~$398k** |

Санити-чек против выручки: при базовом сценарии ([09](09-analytics-kpi.md) §5.2, LTV90 $1.10, CPI $0.90) каждая платная установка к D90 даёт ~$0.20 маржи сверх CPI и продолжает зарабатывать после D90 (LTV180 > LTV90); плюс органика с нулевым CPI. Не-UA часть бюджета (~$318k) отбивается маржой примерно с 1.5–2 млн платных установок по D90-горизонту — заметно быстрее с учётом хвоста LTV и органики; целевой объём года 1 (6–10 млн установок, [02](02-market.md) §1.2) даёт кратный запас. При пессимистичном сценарии проект останавливается на гейте Прохода Г с потерями ≤$300k — это цена проверки ставки №1 рынка.
