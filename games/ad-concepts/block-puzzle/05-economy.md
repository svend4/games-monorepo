# 05 — Игровая экономика

Навигация: [← Мета](04-meta-progression.md) | [README](README.md) | [Монетизация →](06-monetization.md)

Числа этой главы согласованы с монетизацией ([06](06-monetization.md)) и юнит-экономикой ([09](09-analytics-kpi.md) §5). Изменение любого номинала — только синхронно во всех трёх главах.

## 1. Валюты и ресурсы

| Ресурс | Тип | Хранится | Назначение |
|--------|-----|----------|-----------|
| **Монеты** | Soft currency | Да | Единственная валюта: бустеры, continue, скины, восстановление стрика |
| **Бустеры** (Молот / Обмен / Отмена) | Инвентарные предметы | Да | Инструменты спасения в партии ([03](03-core-gameplay.md) §6) |
| **Билеты Поля** | Инвентарный предмет | Да (cap 3) | Дополнительный запуск Фигурного поля |
| **Звёзды** | Прогрессия | Да (по уровням) | Гейты глав, сундуки — не тратятся, не покупаются |
| **Сезонные очки** | Прогрессия | В сезоне | Трек сезона, сгорают в конце |
| **Заряд Прилива** | Сессионный | Нет (в партии) | Механика ядра, вне экономики |

Осознанное решение: **одна валюта**. Вторая (hard currency) добавляется не раньше зрелой фазы (год 1+), когда появится контент под неё; преждевременный gem-слой — классическая ошибка казуалок, размывающая ценность офферов.

**Энергии/жизней нет** — вход в игру всегда бесплатен. Монетизируем спасение и ускорение, а не доступ (критично для IAA-модели: любой барьер входа режет сессии → режет показы).

## 4. Earn-rate и расход по дням (день 1–30, базовый активный игрок)

Читается так: первая неделя — профицит (обучение ценности монет, нулевая фрустрация → ретеншен, который делает 89% ad-LTV), недели 2–3 — равновесие, к дням 25–30 — управляемый дефицит, совпадающий с окном оффера паков и Season Pass ([06](06-monetization.md) §5, §7).

Формула прихода (для тюнинга): `Earn(t) ≈ 285 + 65·e^(−t/4) + 150·[t mod 7 = 0] + 200·[t = 1]` (последнее слагаемое — стартовый бонус FTUE); расход растёт с fail rate по кривой сложности [03](03-core-gameplay.md) §5.

## 5. Бустеры: ценность и прайсинг

| Бустер | Цена (монеты) | Ценность для игрока | Расчёт справедливости цены |
|--------|---------------|---------------------|-----------------------------|
| Отмена | 80 | Исправить мисклик/просчёт | Дешевле всех: страхует ввод, а не навык; частота ошибок ввода у 45+ выше — низкая цена = защита ретеншена |
| Обмен | 120 | Новая тройка фигур | ≈ стоимость «маленького continue»: спасает из полутупика |
| Молот | 150 | Точечно открыть клетку (снять камень/пробить дыру) | Самый мощный: превращает гарантированный fail в победу; ×1.9 цены Отмены |
| Continue №1 | 200 | Сохранить партию/прогресс уровня | ≈ дневной свободный профицит недели 2 — «раз в день бесплатно не больно» |
| Continue №2 | 400 | Жадность/рекорд | Прогрессия ×2 против абуза; альтернатива — rewarded RW-1 только на первом continue |

Правило: у каждого платного действия есть рекламная альтернатива хотя бы раз в день (RW-1, RW-3) — так мы монетизируем и неплатящих ([06](06-monetization.md) §2).

## 6. Инфляционные риски и контроль

| Риск | Механизм контроля |
|------|-------------------|
| Накопление у ветеранов (миссии+турниры > траты) | Долгосрочные sinks: скины 1000–5000, ротация магазина скинов каждый сезон; при балансе >5000 показываем «витрину недели» |
| Rewarded ×2 раздувает приход | RW-2 ограничен 3/день (cap в [06](06-monetization.md) §2); удвоение применяется к награде уровня, не к линиям |
| Обесценивание continue | Цена №2 = ×2; отсутствие №3 — монетами нельзя купить бессмертие, рекорды лиги остаются честными |
| Щедрость ивентов | Бюджет ивента ≤ 15% недельного earn-rate; калькулятор бюджета — обязательная часть спеки любого ивента ([08](08-liveops.md) §4) |
| KPI-контроль | Дашборд `coins_earned / coins_spent` по когортам; целевой коридор отношения 0.95–1.15 после D14; алерт вне коридора ([09](09-analytics-kpi.md) §2) |

## 7. Точки дефицита, создающие спрос

1. **Босс-уровни (каждый 10-й)** — пик fail rate до 25–30% → спрос на Молот/continue в моменте. Пик всегда с передышкой после — фрустрация не накапливается.
2. **Дни 25–30 lifetime** — плановый дефицит баланса (таблица §4) → окно паков $1.99–4.99 и Season Pass.
3. **Конец сезона (дни 24–28 сезона)** — не закрытый трек → catch-up оффер пасса ([04](04-meta-progression.md) §6).
4. **Восстановление стрика** — потеря серии 6+ дней эмоционально дорога → 100 монет/rewarded; конверсия в первую трату у неплатящих.
5. **Второй запуск Фигурного поля** — контентный дефицит (1 бесплатно/день) → RW-4 или билет; поле дня исчезает в полночь (мягкий FOMO без таймера в ядре).

Каждая точка дефицита имеет бесплатный выход (реклама/ожидание/навык) — стандарт «честной сделки» проекта ([01](01-concept.md) §7).
