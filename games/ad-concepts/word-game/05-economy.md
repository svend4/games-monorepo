# 05 — Игровая экономика

Документ: экономическая модель WordGrove. Владелец: ГД-экономист. Версия 1.0.
Числа этой главы согласованы с [06-monetization.md](06-monetization.md) (цены, плейсменты) и [09-analytics-kpi.md](09-analytics-kpi.md) (KPI, LTV).

## 1. Валюты и ресурсы

| Ресурс | Тип | Роль | Кап | Покупается за деньги? |
|--------|-----|------|-----|----------------------|
| **Монеты** | Основная мягкая валюта | Покупка подсказок, заморозка стрика, догон ивентов | Нет | Да (IAP-полка) |
| **Жёлуди** | Втор. валюта (копилка) | Награда за бонусные слова → конвертация в монеты через rewarded | Копилка 200 | Нет |
| **Лампа** | Расходник-подсказка | Случайная буква | 99 | Через монеты / наборы IAP |
| **Прицел** | Расходник-подсказка | Выбранная клетка | 99 | Через монеты / наборы IAP |
| **Ракета** | Расходник-подсказка | 5 случайных букв | 99 | Через монеты / наборы IAP |
| **Листья** | Сезонная валюта | Прогресс сезонного трека | Сброс сезоном | Нет |
| **Заморозка стрика** | Расходник | Спасение стрика | 3 | Через монеты / входит в подписку |

Принципы: одна покупаемая валюта (монеты) — экономика читаема для аудитории 45+ и для нас; жёлуди — рекламная валюта (их единственный «выход» — rewarded RV-5, см. [06-monetization.md](06-monetization.md)); листья — ивентовая, сгорают.

## 2. Sources / Sinks по каждой валюте

### 2.1 Монеты

| Источник (source) | Объём | Условие |
|-------------------|-------|---------|
| Завершение уровня | 20 + 5 за «блестящий проход» | всегда |
| Daily-кроссворд | 40 | 1/день |
| Стрик-вехи | 3д: 50; 7д: 120; 14д: 250; 30д: 600 | по календарю |
| Daily-миссии (3 шт.) | 30–60 суммарно ~120/день | при выполнении |
| Weekly-миссии | 150–250, суммарно ~550/нед | при выполнении |
| Колесо бонуса (после daily) | 25–500, EV ≈ 60; ×2 за rewarded (RV-3) | 1/день |
| Копилка жёлудей → монеты | до 200 за открытие (RV-5) | rewarded |
| Альбом региона завершён | 300 | раз в регион |
| Ивенты | 200–500/нед EV | по календарю |
| IAP / подписка +20% к наградам | по полке [06-monetization.md](06-monetization.md) | покупка |

| Сток (sink) | Цена | Ожид. частота (D14+) |
|-------------|------|----------------------|
| Лампа | 100 | 1,1/день |
| Прицел | 150 | 0,4/день |
| Ракета | 350 | 0,15/день |
| Заморозка стрика | 500 | 0,05/день |
| Догон дня темат. недели | 300 | 0,1/день (в ивент) |
| Повтор колеса (3-й спин) | 200 | 0,1/день |

### 2.2 Жёлуди

- Sources: бонусное слово +2; отдельные миссии +10–20; ивент «Двойные жёлуди» ×2.
- Sinks: конвертация в монеты 1:1 при открытии копилки (RV-5 или подписка); рейтинг лиги (жёлуди недели = очки лиги, не тратятся).
- Кап копилки 200 — переполнение сгорает: создаёт ритм «открой раз в 1–2 дня» → стабильные rewarded-показы.

### 2.3 Подсказки-расходники

- Sources: покупка за монеты (основной), FTUE-выдача (2 Лампы на уровне 7), rewarded RV-1 (1 бесплатная Лампа/уровень), сезонный трек, IAP-наборы.
- Sinks: применение в уровне. Расходники без экспирации (доверие аудитории).

## 3. Стартовый баланс

| Ресурс | Старт | Обоснование |
|--------|-------|-------------|
| Монеты | 300 | Хватает на ~3 Лампы — игрок учится тратить, не успев накопить «подушку» |
| Лампы | 2 (выдача на ур. 7) | Обучение механике подсказки «бесплатно» |
| Прицел/Ракета | 0 | Знакомство через сезонный трек и магазин |

## 5. Инфляционные риски

| Риск | Механизм | Контроль |
|------|----------|----------|
| Накопление у казуалов, играющих только daily | Daily+стрик дают ~100–160/день при нулевых тратах | Их sink — заморозки стрика и догоны тематических недель; допустимо: они смотрят rewarded и мало трат создают |
| Ивентные выбросы монет | +500/нед EV | Ивентовые награды частично в жёлудях/листьях, не в монетах |
| Rewarded-конвейер копилки | До 200 монет за просмотр | Кап копилки + скорость набора жёлудей (нужно ~100 бонусных слов на полную) |
| Пауэр-игроки (20+ уровней/день) | Earn 500+/день | Их траты растут пропорционально (больше пиков); DDA поднимает баккет ([03-core-gameplay.md](03-core-gameplay.md), 6.3) |
| Дубли открыток не сжигают ничего | — | Дубли невозможны (детерминированная выдача) — риска нет |

Мониторинг: дашборд `economy_balance` — медианный баланс по когортам дней жизни; алерт при отклонении медианы D30 от коридора 400–900 монет ([09-analytics-kpi.md](09-analytics-kpi.md), раздел 2).

## 6. Каннибализация подпиской (безлимитная Лампа)

Подписка даёт безлимит Ламп с кулдауном 3 мин ([06-monetization.md](06-monetization.md), раздел 5). Оценка выпадающего стока: подписчик экономит ~1,1 Лампы/день = 110 монет/день → его монетный дефицит почти исчезает → IAP-монеты подписчик не покупает. Это **осознанно**: ARPU подписчика ($8,99/мес gross ≈ $0,21/день net) в ~2,5 раза выше всего blended ARPDAU ($0,085) и на порядок выше IAP-компонента ($0,011, [06-monetization.md](06-monetization.md), раздел 8.3); подписка «съедает» IAP-монеты, но это выгодный обмен. Прицел и Ракета в подписку НЕ входят — точка доп. монетизации остаётся даже у подписчиков.

## 7. Точки дефицита, создающие спрос

1. **Пиковые уровни (каждый 10-й):** solve-time ×2, спрос на Ракету (350) — главный монетный сток.
2. **Структурный дефицит D15+** (таблица раздела 4): earn падает (меньше уровней/день, вехи стрика реже), sink растёт (сложность выше) — окно первой покупки.
3. **Стрик под угрозой:** пропуск дня при стрике ≥ 7 — эмоционально самая горячая точка; заморозка 500 монет или подписка (авто-защита). Пуш-триггер — [08-liveops.md](08-liveops.md), раздел 5.
4. **Тематическая неделя, пропущенный день:** 300 монет за догон — временнОй дефицит.
5. **Копилка полна:** дефицит «слота» — решается просмотром rewarded (не монетами) — специально, чтобы рекламная и монетная воронки не конкурировали.

## 8. Экономика подсказок: ценность в pain-единицах

Оценка ценности бустеров через сэкономленное время (медианный игрок, баккет D3):

| Подсказка | Экономия времени | Монет/мин экономии | Комментарий |
|-----------|------------------|--------------------|-------------|
| Лампа (100) | ~45 сек | 133 | Импульсная, дешёвая, частая |
| Прицел (150) | ~70 сек (точечный тупик) | 129 | Чуть «выгоднее» в кризис — осознанный выбор |
| Ракета (350) | ~3 мин (пиковые уровни) | 117 | «Выгоднейшая» по курсу — премиум-ощущение |

Курс выровнен в узком коридоре 115–135 монет/мин: нет строго доминирующей опции, выбор остаётся вкусовым — это удерживает спрос на все три SKU наборов IAP ([06-monetization.md](06-monetization.md), раздел 5).

## 9. Экономика по гео

- Числа выше — Tier-1. Для Tier-2/3 экономика идентична (единый баланс), различается только прайсинг IAP/подписки (локальные цены, [06-monetization.md](06-monetization.md), раздел 7).
- RU-запуск: тот же баланс; проверка гипотезы «RU-игрок чаще смотрит rewarded вместо трат монет» — телеметрией, не отдельным балансом.

## 10. Изменение экономики после запуска

- Все числа (награды, цены подсказок, капы) — в remote config; изменение цен подсказок задним числом — только вниз (не девальвировать купленное).
- Каждое изменение экономики — A/B с guardrail-метриками: D7, средний баланс D14, rewarded/DAU, конверсия в первую покупку ([09-analytics-kpi.md](09-analytics-kpi.md), раздел 6).
