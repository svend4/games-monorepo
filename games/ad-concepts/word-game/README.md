# WordGrove — книга проектной документации

**Рабочее название:** WordGrove (рус. витрина — «Словесная роща»)
**Жанр:** word-puzzle кроссвордного типа (колесо букв → слова заполняют сетку), референс Wordscapes
**Статус документа:** рабочая версия 1.0 — концепт-книга до старта Прохода А

---

## Elevator pitch

WordGrove — релакс-кроссворд для аудитории 30–60: свайпаешь буквы по кругу, слова заполняют сетку, каждый паззл продвигает тебя по атласу спокойных пейзажей мира. Ежедневный кроссворд со стриком превращает игру в утренний ритуал «газетного кроссворда», а подписка WordGrove Club делает этот ритуал премиальным: без рекламы, с курируемым премиум-паззлом дня и безлимитом подсказок. Мы заходим в жанр с максимальной долей рекламной выручки (puzzle = 53% всей IAA мобильного гейминга) с самой недообслуженной аудиторией — 45+.

## Модель монетизации одной строкой

Реклама (rewarded за подсказки + interstitial между уровнями + баннер) ~65% выручки + подписка $8,99/мес как ключевой апселл ~22% + разовые IAP монет ~13%.

## Целевая аудитория одной строкой

30–60 лет (ядро 45+, ~65–70% женщины), Tier-1 англоязычные рынки, любители слов и кроссвордов, релакс-мотивация; русский — вторичный рынок на той же кодовой базе.

## Юнит-экономика (базовый сценарий)

ARPDAU $0,085 · D1/D7/D30 = 42/18/8% · LTV(365) ≈ $1,81 · CPI $1,20 · окупаемость UA ~D170 · подробности в [главе 09](09-analytics-kpi.md).
