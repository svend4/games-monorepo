# WordGrove — прототип ядра (Проход А)

Играбельное ядро релакс-кроссворда по [главе 03](../03-core-gameplay.md) и [приложению 11](../11-algorithms.md). Colесо букв — Canvas, сетка и HUD — DOM. Без сборщиков и CDN.

## Запуск

```
python -m http.server 8145 --bind 127.0.0.1 --directory games/ad-concepts
```

Открыть http://127.0.0.1:8145/word-game/prototype/. Работает и с `file://`.

## Управление

Зажми букву в колесе и веди по буквам — линия-след соединяет их, слово показывается над колесом; отпусти — проверка. Слова сетки открываются в клетках кроссворда; валидные слова не из сетки идут в копилку бонусов (+2 монеты). Кнопки: 🔀 перемешать (бесплатно), 💡 подсказка за 100 монет, ⭐ список бонусов, ↻ рестарт уровня.

## Объём Прохода А

Реализовано: колесо 6–7 букв, ввод протяжкой, кроссвордная сетка с открытием, бонусные слова, перемешивание, подсказка, награда за уровень (22 + 5 за проход без подсказок), 10 встроенных русских уровней ([levels.js](levels.js)), переход между уровнями, финальный экран, прогресс в localStorage (`wordgrove.save.v1`).

Данные уровней (`levels.js`) собраны офлайн алгоритмом укладки из 11 §3 и провалидированы: каждое слово составимо из букв колеса, пересечения согласованы, сетка связна. В проде уровни генерируются двуязычным (EN+RU) пайплайном из [приложения 11](../11-algorithms.md); стек — TypeScript + Phaser 3 + Capacitor.

Вне ядра (следующие проходы): подписка WordGrove Club и реклама из [главы 06](../06-monetization.md), мета-атлас, аналитика.

## Смоук-тест (пройден)

`node --check` чист; независимый валидатор всех 10 уровней (составимость слов, согласованность пересечений, связность) — зелёный; живой прогон в браузере: ввод протяжкой (АТОМ), бонус (ТОМ +2 монеты), полное прохождение уровня 1, оверлей победы (+22 +5), переход на уровень 2, сохранение прогресса — без ошибок консоли.
