## 1. Технологический стек

### 1.1 Основной вариант: веб-технологии

| Слой | Выбор | Обоснование |
|------|-------|-------------|
| Движок рендера | **Phaser 3** (+ TypeScript) | 2D-словесная игра — идеальный кейс: сцены, твины, текст, спрайты из коробки; ниже порог найма, чем PixiJS-самосбор; PixiJS — запасной вариант, если упрёмся в перфоманс текста (Phaser использует Pixi-подобный рендер, миграция локализована в слое рендера) |
| Язык | TypeScript строгий | Типы на данные уровней/экономики — меньше ран-тайм багов |
| Обёртка | **Capacitor** | Сборка iOS+Android из одной веб-кодовой базы; доступ к нативным SDK через плагины |
| Реклама | `@capacitor-community/admob` (MVP) → мост **AppLovin MAX** (к soft launch, пишем сами ~2 нед) | Фазность — [06-monetization.md](06-monetization.md), раздел 6.1 |
| IAP/подписки | RevenueCat (Capacitor SDK) | Кросс-платформенные подписки, триалы, серверная валидация, win-back офферы без своего бэкенда |
| Аналитика | Firebase Analytics + BigQuery export; Adjust — атрибуция | Дерево событий — [09-analytics-kpi.md](09-analytics-kpi.md) |
| Remote config / A/B | Firebase Remote Config | Экономика, капы, DDA, пейволлы — всё конфигурируемое ([05-economy.md](05-economy.md), раздел 10) |
| Пуши | Firebase Cloud Messaging + локальные нотификации Capacitor | План — [08-liveops.md](08-liveops.md) |
| Бэкенд | Минимальный: Firebase (config, пуш-сегменты) + статический CDN для пакетов уровней; серверного геймплея нет | Игра офлайн-первая ([03-core-gameplay.md](03-core-gameplay.md), раздел 7) |
| Контент-пайплайн | Node.js CLI-генератор (словари → паззлы → JSON-пакеты) в CI | Алгоритм — [03-core-gameplay.md](03-core-gameplay.md), раздел 5.2 |

### 1.2 Честное сравнение с Unity

| Критерий | Phaser 3 + Capacitor | Unity |
|----------|----------------------|-------|
| Скорость прототипа word-игры | Дни (DOM-скорость итераций, hot reload) | Недели (тяжелее цикл сборки) |
| Перфоманс 2D-текста/твинов | Достаточный с запасом (наша сцена — сетка + колесо) | Избыточный для задачи |
| Вес сборки | ~15–25 МБ | 40–80 МБ (важно для mid-range Android ЦА) |
| Ad-SDK зрелость | **Слабое место**: мосты для MAX пишем/поддерживаем сами; AdMob-плагин комьюнити | Эталонная: официальные пакеты MAX/AdMob/ironSource |
| Найм | Веб-разработчики дешевле и доступнее | Unity-мидл дороже на ~20–30% |
| Порт на новые платформы | Web-версия почти бесплатно (плейэбл-креативы! витрина в браузере) | WebGL-экспорт тяжёлый |
| Риск платформы | Capacitor-мосты — наша ответственность | Runtime Fee-история напомнила о вендор-риске |
| **Вердикт** | **Выбираем**: профиль игры (2D, текст, офлайн, лёгкая сцена) идеально ложится в веб-стек; экономия бюджета ~15% | Берём, если на Проходе В мост MAX сорвёт сроки > 4 нед (план Б зафиксирован) |

Отдельный бонус веб-стека: генератор уровней и игровой рендер — один язык (TS), один репозиторий; плейэбл-креативы для UA собираются из игрового кода почти бесплатно (важно: пост-ATT UA живёт креативами — [02-market.md](02-market.md), раздел 5).

## 2. Состав работ (эпики)

1. **Ядро**: рендер сетки/колеса, ввод (свайп+тап), валидация, победа, сохранения.
2. **Контент-пайплайн**: словари EN/RU, генератор, скоринг сложности, пакеты, QA-тулинг.
3. **Мета**: атлас, открытки, daily+стрик, копилка, миссии, сезон, лига.
4. **Экономика**: валюты, магазин, инвентарь, remote config баланса.
5. **Монетизация**: медиация, 10 плейсментов, капы, пейволл, RevenueCat.
6. **Аналитика**: дерево событий, ILRD, дашборды, A/B-каркас.
7. **Лайвопс-тулинг**: CMS тем daily, календарь ивентов, пуш-сегменты.
8. **UX/полировка**: FTUE, доступность, тёмная тема, локализация UI EN/RU.
9. **Платформа**: сборки, сторы, крэш-репортинг, CI/CD.

## 3. Роадмап проходами (от простого к сложному)

### Проход А — играбельное ядро (6 недель)

- **Скоуп:** эпики 1 + 2 (EN-словарь, генератор v1, 300 уровней), сохранения, 30 «золотых» FTUE-уровней, минимальный UI (атлас-заглушка, экран уровня, победа). Без рекламы, меты, IAP.
- **DoD:** играбельный билд iOS+Android через Capacitor; 60 fps на Moto G-класса; 20 внутренних плейтестеров прошли 50+ уровней; solve-time p50 по баккетам в коридорах ±25% от расчётных ([03-core-gameplay.md](03-core-gameplay.md), раздел 6); crash-free ≥ 99%; пайплайн генерации выдаёт пакет 100 уровней за < 10 мин в CI.
- **Гейт:** внутренний фан-тест — 70%+ плейтестеров возвращаются на 3-й день сами (прокси D3).

### Проход Б — мета и экономика (6 недель)

- **Скоуп:** эпики 3 + 4: daily+стрик, копилка, атлас/открытки, миссии, магазин за монеты, remote config баланса; контент до 600 уровней; FTUE v1 полный ([07-ux-ui-ftue.md](07-ux-ui-ftue.md)).
- **DoD:** экономика соответствует таблице D1–D30 из [05-economy.md](05-economy.md) в симуляторе (скрипт-симуляция медианного игрока — обязательный артефакт); все мета-слои включаются по расписанию ([04-meta-progression.md](04-meta-progression.md), раздел 8); дизайн-ревью пейволл-точек пройдено.
- **Гейт:** friends&family (50–100 игроков, TestFlight/Internal testing): D1 ≥ 35% как ранний сигнал.

### Проход В — монетизация и аналитика (6 недель)

- **Скоуп:** эпики 5 + 6: AdMob-интеграция → мост MAX, все 10 плейсментов с капами ([06-monetization.md](06-monetization.md), раздел 3), RevenueCat (подписка+полка), полное дерево событий, дашборды `ads_health`/`economy_balance`, A/B-каркас; сезонный трек; лайвопс-тулинг v1 (эпик 7 частично).
- **DoD:** каждый плейсмент отдаёт ILRD-выручку в аналитике; SSV-валидация rewarded работает; подписка проходит полный цикл (триал→оплата→отмена→win-back) в сэндбоксах обоих сторов; интерстишл-правила (все 10 из главы 06) покрыты автотестами; crash-free ≥ 99,5%.
- **Гейт:** техтест на 500–1000 закупленных установок (T2-гео): SDK-стек стабилен, события сходятся со сторами/сетями с расхождением < 5%.

### Проход Г — soft launch (10–12 недель)

- **Скоуп:** запуск в 2–3 гео (Канада + Австралия как T1-прокси; Филиппины как T2-объём); UA-бюджет $30–50 тыс.; 3 итерационных цикла по 3–4 недели: замер → гипотезы → релиз; контент до 1200 уровней; лайвопс-календарь недель 1–4 ([08-liveops.md](08-liveops.md)); A/B M1–M2 из плана ([09-analytics-kpi.md](09-analytics-kpi.md), раздел 6).
- **DoD (метрики базового сценария):** D1 ≥ 40%, D7 ≥ 16%, ARPDAU ≥ $0,07, триалы ≥ 2% установок D30, crash-free ≥ 99,5%, прогнозный ROAS D365 ≥ 120%.
- **Гейт (go/no-go global):** kill-критерии из [09-analytics-kpi.md](09-analytics-kpi.md), раздел 4.3. No-go → ещё 1 итерация или закрытие проекта (решение продюсера + данные, без «ещё чуть-чуть» без гипотез).

### Проход Д — global (8 недель до запуска + ongoing)

- **Скоуп:** запуск US/UK + остальной мир; масштабирование UA по стоп-лосс правилам; лайвопс-календарь Q1 ([08-liveops.md](08-liveops.md), раздел 6); ASO-пакет; вторая волна A/B (M3–M6); подготовка RU-пакета (словарь, локализация) как отдельного go/no-go по чек-листу: юридика платежей, стор-доступность, прогноз ROI ≥ 0 на органике.
- **DoD:** план/факт KPI-ревью ежемесячно; выручка соответствует коридору года 1 ([02-market.md](02-market.md), раздел 1.4) или роадмап пересматривается.

Итого до global: **~9 месяцев** (36–38 недель работ: 6+6+6+10–12+8, + буфер).

## 4. Команда и роли

| Роль | FTE | Проходы | Зона |
|------|-----|---------|------|
| Продюсер / ГД | 1,0 | А–Д | Видение, приоритеты, монетизация, UA-надзор |
| Геймдизайнер-экономист | 0,5 → 1,0 (с Прохода Б) | Б–Д | Баланс, симуляции, A/B-дизайн |
| Разработчик TS (лид) | 1,0 | А–Д | Ядро, архитектура, мосты SDK |
| Разработчик TS | 1,0 | А–Д | Мета, UI, лайвопс-тулинг |
| UX/UI-художник | 1,0 | А–Д | Экраны, пейзажи (частично сток+докраска), анимации |
| Лингвист-контентщик | 0,5 | А–Д | Словари, курирование daily, QA контента ([03-core-gameplay.md](03-core-gameplay.md), 5.3) |
| QA | 0,5 → 1,0 (с Прохода В) | Б–Д | Тест-планы, автотесты правил рекламы |
| UA-менеджер | 0,5 (с Прохода Г) | Г–Д | Закупка, креативы (+подрядчик на видео) |
| Аналитик | 0,5 (с Прохода В) | В–Д | Дашборды, LTV-модель, A/B-статистика |

Пик: ~7,5 FTE (Проходы Г–Д); по фазам: А ≈ 5,0 · Б ≈ 6,0 · В ≈ 7,0 · Г–Д ≈ 7,5. Средневзвешенно за 9 месяцев ≈ 6,4 FTE — эта цифра идёт в бюджет ФОТ (раздел 5).

## 6. Риски производства и митигация

| # | Риск | Вероятн. | Импакт | Митигция |
|---|------|----------|--------|----------|
| 1 | Мост Capacitor↔MAX дороже/дольше плана | Средняя | +2–4 нед Прохода В | Начинаем мост в Проходе Б параллельно; план Б: остаёмся на AdMob-медиации до M2 global (потеря ~10–15% eCPM, посчитано в модели как пессимист-фактор) |
| 2 | Перфоманс Phaser на старых Android | Низкая | Лаги у ЦА | Бюджет 60 fps с Прохода А в DoD; запасной рендер PixiJS; девайс-лаборатория из 5 бюджетных устройств |
| 3 | Качество генерации RU-словаря (омонимия, формы) | Средняя | Задержка RU | RU — отдельный go/no-go Прохода Д, не блокирует основной план |
| 4 | Отклонение сторов (реклама/подписки) | Низкая | +1–2 нед | Прозрачный триал, guideline-ревью перед сабмитом; прецеденты жанра изучены |
| 5 | Выгорание контент-пайплайна (уровни хуже к 1000+) | Средняя | Ретеншен хвоста | Телеметрический QA-контур (авто-флаг плохих уровней — [03-core-gameplay.md](03-core-gameplay.md), 5.3) |
| 6 | Ключевой разработчик уходит | Средняя | −30% velocity | Два TS-разработчика с перекрытием зон; вся логика — данные+конфиги, bus-factor снижен |
| 7 | CPI выше плана на soft launch | Высокая | Экономика не сходится | Это не производственный сбой, а сигнал: креативная итерация ×3, затем kill-критерии ([09-analytics-kpi.md](09-analytics-kpi.md), 4.3) — дешёвое закрытие тоже результат |

## 7. Процессы

- Спринты 2 недели; билд на девайсы — каждую пятницу; плейтест всей командой — еженедельно (30 мин, свежая сборка).
- CI/CD: сборка iOS/Android + прогон автотестов (правила рекламы, экономика-симуляция, контент-валидаторы) на каждый merge.
- Definition of Done фичи: код + события аналитики + remote config + автотест + строка в чейнджлоге плейтеста.
- Все решения по монетизации/экономике — через лог решений с датой и данными (дисциплина, спасающая от «настроечного дрейфа»).
