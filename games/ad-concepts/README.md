# Ad-concepts — книги документации рекламно-монетизируемых игр

Три полные книги проектной документации (GDD + продюсерская документация) для трёх лучших сочетаний «жанр × модель монетизации», отобранных по итогам верифицированного исследования рынка мобильной рекламы (июль 2026, источники: Sensor Tower State of Mobile 2026, AppsFlyer State of App Monetization 2026, Tenjin Q1 2026, Appodeal Q4 2024; 17 из 18 ключевых цифр прошли независимый факт-чекинг).

## Почему именно эти три концепта

1. **Puzzle — король рекламной выручки**: 53% всей ad-выручки мобильного гейминга приходится на puzzle-игры (аркады — вторые с 13%). Топ-заработчики: Block Blast! ($127 млн за 5 мес 2026), Vita Mahjong ($89,8 млн), Candy Crush ($81,1 млн).
2. **Hybrid-casual — единственная растущая казуальная модель**: +20% IAP до $4,2 млрд в 2025; чистый hyper-casual мёртв после ATT. ~72% студий совмещают рекламу и IAP.
3. **Rewarded-видео — самый дорогой массовый формат**: eCPM в США $16–20 против $14 у interstitial и $0,45–0,68 у баннеров; 3+ rewarded-плейсмента дают 2,4× к рекламному ARPDAU.
4. **Старшая Tier-1 аудитория (солитер/word) — самая лояльная и платёжеспособная**: 30% игроков США старше 50 лет, длинные ежедневные сессии, максимальная доля IAA-выручки среди жанров (Tenjin).

## Сравнение вариантов

| | [Block Surge](block-puzzle/README.md) | [Orchard Peaks](solitaire-meta/README.md) | [WordGrove](word-game/README.md) |
|---|---|---|---|
| Жанр | block-puzzle без таймера | TriPeaks-солитер + сад-мета | word-кроссворд (колесо букв) |
| Референсы | Block Blast!, Color Block Jam | Solitaire Grand Harvest, Vita Mahjong | Wordscapes |
| Модель | реклама 70% → 60% / IAP | гибрид ~50/50 IAP/реклама | реклама ~65% + подписка ~22% + IAP |
| Аудитория | казуал 25–55, Tier-1 | женщины 45–70, US/CA/UK/AU | 30–60, EN Tier-1 (+RU вторично) |
| ARPDAU (база) | $0,15 | $0,22 | $0,085 |
| LTV (база) | $1,10 (D90) | $3,12 (D180) | $1,81 (D365) |
| CPI (допущение) | $0,90 | $2,30 | $1,20 |
| Окупаемость UA | ~день 52 | ~день 100–110 | ~день 170 |
| Бюджет до global | ~$398 тыс. (~32 нед., 5 FTE) | ~$616 тыс. (~10 мес.) | ~$450 тыс. (36–38 нед.) |
| Главный риск | перегретая ниша, CPI может уйти >$1,50 | CPI карточного казуала в Tier-1 может стоить $3+ | конверсия триала 55% — верхняя граница нормы |

## Как выбирать

- **Минимальный риск и самый быстрый возврат** → Block Surge: самое дешёвое производство, payback ~D52, простейшее ядро. Плата — самая конкурентная ниша.
- **Максимальный потолок LTV и выручки** → Orchard Peaks: модель Grand Harvest с самым высоким ARPDAU ($0,22) и самой платёжеспособной аудиторией. Плата — дорогой трафик и самая сложная мета в производстве.
- **Подписочная страховка от eCPM-циклов** → WordGrove: единственный концепт с растущим подписочным компонентом (подписки в гибридах выросли с 4% до 7% выручки). Плата — длинный payback, нужен оборотный капитал под UA.

Все три книги написаны на общем стеке (Phaser 3 + TypeScript + Capacitor, медиация AppLovin MAX / AdMob) — ядро команды и инфраструктура переиспользуются между проектами.

## Структура каждой книги

11 документов: README (обложка и оглавление) + главы 01-concept, 02-market, 03-core-gameplay, 04-meta-progression, 05-economy, 06-monetization (полная карта рекламных плейсментов с триггерами, капами и долями выручки), 07-ux-ui-ftue, 08-liveops, 09-analytics-kpi (дерево событий, юнит-экономика в трёх сценариях, план A/B), 10-production (роадмап проходами А→Д с DoD-критериями, команда, бюджет, риски).
