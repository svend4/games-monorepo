Что внутри каждого прототипа

Каждый прототип — эволюция по проходам, слои добавлены поверх ядра без переписывания (сейвы обратно совместимы между проходами):

  • Проход А — играбельное ядро: game.js (drag&drop / карты / колесо букв, localStorage).
  • Проход Б — мета и экономика: economy.js + meta.js (валюты, бустеры, карта/сад/атлас, стрики, миссии).
  • Проход В — монетизация и аналитика: monetize.js + analytics.js (реклама-заглушки с eCPM-моделью, IAP-полка, подписка, живой KPI-дашборд). Реклама и покупки — только симуляция, с меткой «СИМУЛЯЦИЯ».
  • Проход Г — soft-launch cockpit: sim.js + experiments.js (детерминированный симулятор экономики из приложения 12, запуск и как node sim.js; A/B; панель тюнинга; гейты go/iterate/kill).
  • Проход Д — global: onboarding.js (FTUE первого запуска), store-listing.md (ASO-пакет), store-preview.html (мокап карточки).

Внутри игры: 🛒 магазин · 📊 KPI-дашборд · 🚀 soft-launch cockpit · ❔ повтор обучения. Симуляторы прогоняются офлайн: node <игра>/prototype/sim.js.

Все рекламные показы, покупки и подписки в прототипах — симуляция без реальных рекламных сетей, платежей и сбора данных; в проде по книгам это AppLovin MAX / AdMob + App Store / Google Play Billing. Карточки стора — дизайн-превью собственных концептов, а не копии страниц реального App Store / Google Play. Рыночные цифры — из открытых отчётов Sensor Tower / AppsFlyer / Tenjin / Appodeal (2024–2026), проверены факт-чекингом; см. книги GDD.
