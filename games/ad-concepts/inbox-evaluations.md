# Входящие концепты — оценка для портфеля

Оценка сторонних прототипов (экспорты Google AI Studio / Gemini, присланы владельцем в июле 2026)
по методике портфеля ad-concepts: жанр и рыночная ниша (данные исследования — [README](README.md)),
пригодность к рекламной монетизации, стоимость доводки, вердикт. Исходники распакованы вне репо
(scratchpad сессии); сюда занесены только оценки.

Общее у всех трёх: нативный Android (Kotlin + Jetpack Compose), package `com.example.*`
(в стор нельзя без переименования), нет монетизации/аналитики/локализации, тесты-заглушки,
другой стек относительно нашего прод-конвейера (TS + Vite + Capacitor + AdProvider).

---

## 1. TetriCross (~3,2 тыс. строк: движок + Room-база + 3 экрана)

**Что это.** Гибрид «полу-Тетрис, полу-кроссворд»: падают тетромино с буквами (7 форм, повороты),
заполненное поле очищается отгадыванием слов по определениям. RU-словарь ~50 слов, очки,
лидерборд, сейвы, режим «секретного слова».

**Рынок.** Свежая механика без прямых аналогов — это и плюс (дифференциация), и риск (несуществующая
ниша). Конфликт мотиваций: word-аудитория (30–60, релакс — наш WordGrove) не любит тайм-прешер
тетриса; тетрис-аудитория не ждёт словесных пауз. Между двумя стульями.

**Монетизируемость.** Средняя: паузы между «стаканами» дают слоты под interstitial, подсказки к
словам — готовый rewarded-крючок. Меты нет — LTV не соберётся без неё (тезис портфеля:
разница между $330 тыс. и $298 млн — это мета).

**Качество кода.** Лучшее из трёх: движок/вью-модель/UI разделены, корректные повороты фигур,
аккуратная Room-схема. Словарь критически мал.

**Вердикт: кандидат в портфель, но через книгу.** Пути: **(а)** порт концепта в наш TS-стек
четвёртой игрой — сначала мини-книга (концепт+экономика+риск ниши), потом ядро (переиспользуем
AdProvider/экономику/i18n/кокпит); **(б)** дешевле — механика как недельный ивент-режим WordGrove
(«буквопад»); **(в)** нативный трек — только если цель учиться Kotlin.

## 2. Retro Emoji Maze (~2,5 тыс. строк, ядро — монолит MainActivity 1,8 тыс.)

**Что это.** 2D-лабиринт в ретро-стиле: DFS-генератор процедурных лабиринтов, эмодзи-аватары
(смайлы/флаги/сердца), сбор звёзд, уровни сложности (размер поля/звёзды/враги), переключаемые
враги и скан-лайн эффект, рекорды в SharedPreferences.

**Рынок.** Аркады — №2 по рекламной выручке гейминга (13% против 53% у puzzle), но ниша
«maze» переполнена примитивами с околонулевым удержанием; без меты это классический профиль
«чистый hyper-casual», который как модель мёртв после ATT (данные исследования). Эмодзи-аватары —
милая, но слабая дифференциация.

**Монетизируемость.** Формально удобная (короткие раунды → interstitial; «вторая жизнь» при
вражеском касании → rewarded), но низкий retention ниши делает LTV мелким.

**Качество кода.** Средне: генератор лабиринтов хорош и компактен, но весь UI — монолит на
1 779 строк, разбирать дороже, чем переписывать.

**Вердикт: в портфель как самостоятельная игра — нет.** Ожидаемая юнит-экономика хуже всех трёх
наших игр. Разумное применение: **мини-игра/ивент внутри существующих** (например, ежедневный
«лабиринт удачи» в Block Surge с наградой монетами — генератор портируется в TS за день) либо
полка «когда-нибудь» до появления идеи меты, которая даст удержание.

## 3. Surreal Circus (~2,9 тыс. строк: 3 аттракциона + синтезатор)

**Что это.** Не игра, а «музыкальная игрушка»: три сюрреалистичных аттракциона (Celestial
Carousel, Gravity Funnel, Ethereal Bubbles), каждое касание рождает гармоничные тона —
собственный чистый Kotlin-синтезатор (AudioTrack, синусоиды с ADSR-огибающей, пентатоника,
поэтому «фальшивых» нот не бывает). Дашборд с рекордами посещений.

**Рынок.** Нет игровой петли: ни цели, ни провала, ни прогресса — это fidget/ASMR-experience.
Такие продукты живут на подписке «relax/sleep» рынка (Calm-сегмент), а не на IAA: в рекламной
модели нет ни пауз для interstitial, ни крючков для rewarded. В наш портфель как продукт
не ложится.

**Вердикт: как продукт — нет; как донор технологий — да, и ценный.** Главная находка —
**пентатонический синтезатор и принцип «каждое действие = музыкальная нота»**: у всех трёх
наших игр звука нет вообще, а это готовый паттерн процедурного аудио без единого аудио-ассета
(идеален для WordGrove — нота на каждую букву протяжки, аккорд на слово; и для «Прилива»
Block Surge — восходящая гамма по комбо). Портирование синтезатора на WebAudio — небольшая,
хорошо очерченная задача.

## Сводная рекомендация

| Проект | В портфель? | Лучшее применение |
|---|---|---|
| TetriCross | возможно (через мини-книгу) | ивент-режим WordGrove или 4-я игра в TS-стеке |
| Retro Emoji Maze | нет | мини-игра «лабиринт удачи» в Block Surge |
| Surreal Circus | нет | донор: WebAudio-синтезатор → звук во все три игры |

Приоритет по соотношению «ценность/усилия», если брать что-то одно: **звук из Surreal Circus**
(закрывает пустующий пункт «звук» из списка доделок до рынка сразу для всех трёх игр), затем
ивент-режимы (TetriCross → WordGrove, Maze → Block Surge), и только потом разговор о четвёртой
игре.
