# Orchard Peaks — прототип ядра (Проход А)

Играбельное ядро TriPeaks-солитера по [главе 03](../03-core-gameplay.md) и [приложению 11](../11-algorithms.md). Без сборщиков и CDN — чистый DOM/CSS, крупный чёткий шрифт для аудитории 45+.

## Запуск

```
python -m http.server 8145 --bind 127.0.0.1 --directory games/ad-concepts
```

Открыть http://127.0.0.1:8145/solitaire-meta/prototype/. Работает и с `file://`.

## Управление

Клик по открытой карте, чей ранг на 1 выше или ниже карты сброса (Туз и Король — соседи), убирает её и продолжает серию. Клик по колоде слева открывает новую карту сброса, но обнуляет серию. Карты урожая 🍎 приносят монеты (начисляются сразу и сохраняются даже при поражении). «Новый расклад» — свежая партия.

## Объём Прохода А

Реализовано: классический расклад 28 карт (3/6/9/10, вскрытие по графу перекрытий), колода добора и сброс, ход ±1 с зацикливанием Т↔К, серия с растущим множителем, карты урожая → монеты, победа/поражение/рестарт, баланс и статистика в localStorage (`orchardPeaks.*`). Упрощённый генератор с отбором расклада по случайным плейаутам — суррогат beam-солвера из 11 §4.

Вне ядра (следующие проходы): сад-мета из [главы 04](../04-meta-progression.md), полная экономика, реклама/IAP, аналитика. Прод — TypeScript + Phaser 3 + Capacitor + AppLovin MAX.

## Смоук-тест (пройден)

`node --check` чист; headless-харнесс (инварианты раскладки, зацикливание рангов, множитель, 300 симуляций без мёртвых состояний); живой прогон в браузере: ход ±1, начисление очков и серии, сбор урожая с немедленным сохранением монет, скрытые aria-метки закрытых карт — без ошибок консоли.
