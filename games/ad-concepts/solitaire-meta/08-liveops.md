# 08. LiveOps и удержание

**Проект:** Orchard Peaks. Назад: [07-ux-ui-ftue.md](07-ux-ui-ftue.md) · Далее: [09-analytics-kpi.md](09-analytics-kpi.md)

LiveOps обслуживает две цели: (1) ретеншен-цели [09-analytics-kpi.md](09-analytics-kpi.md) — D7 первой недели решает 89% рекламного LTV; (2) ритм спроса на монеты — пики дефицита из [05-economy.md](05-economy.md) п. 5.7. Механики описаны в [04-meta-progression.md](04-meta-progression.md), здесь — операционный слой.

## 8.1. Ежедневный цикл (якоря DAU)

| Механика | Время срабатывания | Награда/эффект | Цель |
|---|---|---|---|
| Стрик «Утренняя лейка» | Первый вход дня | 200→1 500 монет по дням ([04-meta-progression.md](04-meta-progression.md) п. 4.4) | Привычка ежедневного входа |
| Колесо ярмарки | Первый вход + второй спин за rewarded (RW4) | EV ≈ 350 монет | Утренний rewarded-показ |
| 3 daily-миссии | Обновление 09:00 локального | 150–400 монет каждая | 2-я и 3-я сессии дня |
| Сундук тёти Марты | 5/10/15 побед за день | 300/700/1 500 монет | Глубина сессий |
| Вечерний «час сада» 19:00–22:00 | Заказы сада дают +10% очков альманаха | — | Вечерний пик, прайм eCPM |

Дизайн дня строится так, чтобы «полный день» (все якоря) занимал 35–45 минут в 2–3 сессии — комфортный максимум ЦА, без чувства повинности при пропуске.

## 8.2. Недельный цикл

| День | Событие |
|---|---|
| Пн | Итоги Лиги урожая (награды почтой), сгорание жетонов ярмарки 09:00, новые weekly-миссии |
| Вт | «Тихий день» — только дейлики (запас прочности расписания) |
| Ср | «Золотая грядка» №1 (48 ч, ×2 урожая) — раз в 2 недели |
| Чт | Пуш-превью ярмарки («Роза уже расставляет прилавки») |
| Пт 12:00 | Старт «Ярмарки выходного дня» + старт новой Лиги |
| Сб–Вс | Пик ярмарки; ивентовый rewarded RW5 активен |
| Вс вечер | Пуш «прилавки закрываются завтра» → воскресный пик IAP ([05-economy.md](05-economy.md) п. 5.7) |

## 8.3. Сезоны

- Сезон = 8–10 недель = сезон года в саду: визуальная смена всех зон, сезонный набор гербария, «Альманах» с premium-треком $7,99 ([04-meta-progression.md](04-meta-progression.md) п. 4.5).
- Финал сезона: неделя «догона» с +50% очков альманаха (анти-FOMO для ЦА) + финальная сценка сюжета сезона.
- Праздничные оверлеи внутри сезонов (6–8/год): Пасха, День матери (ключевой для ЦА!), Хэллоуин-«тыквенная ярмарка», Рождество/зимний сад, весенний фестиваль тюльпанов.

## 8.4. Push-стратегия

Правила: ≤ 1 пуш/день (жёстко), окна 09:30–11:00 и 18:30–20:30 локального; всегда от лица мира игры, не от лица системы; opt-in запрашивается после первой сценки (день 1) с пре-промптом «Марта будет писать вам о саде».

| Триггер | Тайминг | Текст (EN-прод, RU-пример) | Ожидаемый CTR |
|---|---|---|---|
| Стрик под угрозой | 19:30, если нет входа сегодня и стрик ≥ 3 | «Бисквит сторожит вашу лейку. День 5 ждёт!» | 6–9% |
| Заказ почти готов | Урожая хватает на заказ, нет входа 20 ч | «Лаванде не хватает одного солнечного дня» | 5–8% |
| Сценка не просмотрена | Через 22 ч после разблокировки сценки | «Роза заглянула в гости — у неё новости» | 7–10% |
| Ярмарка: старт | Пт 12:00 | «Ярмарка открылась! Первый прилавок — за вами» | 8–12% |
| Жетоны сгорают | Вс 21:00, если жетонов ≥ 50 | «Прилавки закрываются завтра — у вас 140 жетонов» | 10–14% |
| Лига: близко к топ-10 | Вс 12:00, позиции 11–15 | «До корзины наград — одно ведёрко урожая» | 6–9% |
| Возврат D3 (churn-риск) | Нет входа 72 ч | «Сад скучает. Бисквит вырыл для вас подарок» (+ грант 800 монет) | 4–6% |

Гигиена: полный отказ от кликбейта и ложных наград; A/B текстов непрерывно; авто-отключение триггера при CTR < 2% на когорте.

| 4 | Сезон 1 «Позднее лето» стартует официально | Альманах 40 ступеней, сезонный гербарий | Premium-трек альманаха |

| 8 | Челлендж «Сундук Марты ×2» | — | Piggy «Теплица» промо |

## 8.6. Возврат churned-игроков

Сегментация ушедших (нет входа 7+ дней) по последнему состоянию:

| Сегмент | Гипотеза ухода | Механика возврата |
|---|---|---|
| Ушёл на «камне» (3+ поражения на одном уровне) | Фрустрация сложности | Пуш D7 + при входе «лёгкая рука» (D−0.15) + 2 джокера; уровень помечен «Бисквит помог» |
| Ушёл в дефиците монет (< 1 взнос) | Экономическое удушье | Грант 3·E(n) «наследство тёти» + Кошелёк с capом 5/день на 3 дня |
| Ушёл после FTUE (D1–D2) | Не зацепило | Не возвращаем пушами (дёшево и бесполезно), сегмент отдаётся ре-таргетинг UA только при CPI < $0.5 |
| Ветеран (30+ дней игры, ушёл) | Выгорание/сезонность | Письмо-сценка «сад ждал вас» + пропущенные карточки гербария докупаемы за урожай; вход в текущий сезон с бонусом 10 ступеней |
| Подписчик с отменой | Ценность неочевидна | Оффер «месяц за $3.99» однократно + опрос из 1 вопроса |

Канальный микс возврата: пуши (бесплатно) → email (собираем opt-in в игре с подарком) → ре-таргетинг (только сегмент «ветераны», окупаемость считаем как отдельную UA-кампанию в [09-analytics-kpi.md](09-analytics-kpi.md)).

## 8.7. Операционные требования

- Все номиналы наград, капы, расписания — в remote config; релиз ивента не требует сборки клиента ([10-production.md](10-production.md), веб-стек это даёт бесплатно).
- Ивенты собираются из 5 шаблонов (ярмарка, множитель, лига, сундук, оверлей) + контент-пак; новый тип ивента — не чаще 1 раза в квартал, чтобы не перегружать ЦА обучением.
- Дежурство LiveOps: понедельник (итоги лиги + сгорание жетонов) — самый рискованный день; ролбэк-план для каждого ивента обязателен.
- Комьюнити: официальная Facebook-группа (ядро ЦА живёт там) с ритуалом «скриншот сада недели»; ответы на отзывы в сторах ≤ 48 ч.
