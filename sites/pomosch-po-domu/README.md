# Помощь по дому — лендинг бытовых услуг

Учебный набор: рекламные/документные страницы + генераторы прайса.
**Markdown — источник истины**, HTML/JSON/CSV генерируются из него.

## Содержимое

- **Контент** (4 документа, пара `.md` → `.html`):
  `obyavlenie` (объявление), `uslugi-i-ceny` (услуги и цены), `dogovor` (договор), `anketa-pamyatka` (анкета + памятка).
- **Данные** (генерируются, не редактировать вручную):
  `database.json`, `prais.json`, `ceny_svodka.csv`, `ceny_svodka_php.csv`.
- **Инструменты**:
  - `generate_all.py` — парсит все `.md` → `database.json`
  - `generate_data.py` — `uslugi-i-ceny.md` → `prais.json`
  - `sobrat_ceny.py` / `sobrat_ceny.php` — `.md` → CSV-сводка
  - `prais.php` — витрина прайса с поиском и фильтром по цене (читает `database.json`)

## Важно: плоская структура

Все скрипты рассчитаны на то, что файлы лежат **в одной папке** (читают соседние `*.md` и `database.json`
через `__DIR__` / директорию скрипта). Поэтому структура намеренно плоская — **не разносите файлы
по подпапкам** без правки путей внутри скриптов.

Запуск витрины: `http://localhost/01/sites/pomosch-po-domu/prais.php`.
