# Связь с продуктом и тезисом

[⌂ Вики](../../README.md) · [Позиции](../README.md) · [Agent Harness](README.md) · Связь с продуктом

Страница показывает, как роль Agent Harness встраивается в главный тезис Mirendil — **самоускоряющийся ИИ (self-accelerating AI)** — и в продукт-платформу «vibe research». Факты (из анонсов и вакансий) отделены от аналитической реконструкции.

## Тезис в двух словах (факт)

Mirendil обучает специализированные фронтир-модели, которые эксперты именно в **ИИ-R&D** — дизайн экспериментов, перебор гиперпараметров, оценка моделей, итеративное дообучение — и строит вокруг них продукт-платформу. Заявленная цель — «democratize frontier AI R&D across scientific disciplines»: сжать месяцы исследовательского цикла до дней автоматических итераций и открыть доступ к фронтир-R&D, который сейчас заперт в нескольких лабораториях.

Нейшабур (CEO) формулирует это как задачу «направить систему в конкретный угол [пространства задач] и добиться быстрого улучшения — это и есть технология self-accelerating AI».

## Где в этой машине стоит Agent Harness

*Аналитическая реконструкция связи роли с продуктом.*

Модель — это «мозг». Agent harness — это то, что даёт мозгу руки, память и обратную связь и замыкает исследовательский цикл:

```
        ┌─────────────────────────────────────────────┐
        │            ЦИКЛ SELF-ACCELERATING AI          │
        │                                               │
   ┌────▼─────┐   ┌────────────┐   ┌──────────────┐    │
   │ ЭКСПЕРИ- │──▶│   ОЦЕНКА    │──▶│ ДООБУЧЕНИЕ /  │────┘
   │  МЕНТ    │   │(evaluation) │   │ след. итерация│
   └────▲─────┘   └────────────┘   └──────────────┘
        │                │
        │        agent harness обслуживает КАЖДЫЙ шаг:
        │        • agent loop запускает эксперимент
        │        • оркестрация масштабирует перебор
        │        • guardrails держат длинную задачу
        │        • eval/observability измеряют результат
        └────────── extension layer подключает инструменты домена
```

- **Эксперимент.** Agent loop и capability primitives дают модели запускать код, jobs и эксперименты — превращают «совет» в действие.
- **Масштаб.** Оркестрация и горизонтальное масштабирование позволяют гнать множество экспериментов параллельно — от этого напрямую зависит скорость «ускорения шага».
- **Устойчивость.** Guardrails и reliability держат многочасовые (long-horizon) сессии, без которых автоматический цикл не окупается.
- **Оценка.** Evaluation и observability стоят в центре цикла: без измерения поведения нельзя направлять систему «в нужный угол» и ловить регрессии.
- **Расширяемость.** Extension layer быстро подключает инструменты конкретных научных доменов.

## Связь с «vibe research» (факт + реконструкция)

a16z называет слой для менее технических пользователей **«vibe research»**: чтобы доменный учёный (drug discovery, химия, биология, робототехника, материаловедение) сам ставил эксперименты, не будучи ML-инженером *(факт — так описан продукт)*.

*Аналитическая реконструкция:* именно agent harness делает такой слой возможным. Prompt scaffolding и tool integrations прячут сложность обвязки за простым интерфейсом; extension layer подключает инструменты конкретного домена; guardrails и observability делают поведение агентов достаточно надёжным и прозрачным, чтобы им можно было доверить исследование без ручного контроля инженера на каждом шаге. Без крепкой обвязки «vibe research» остаётся демонстрацией, а не продуктом.

## Отношение к спору о безопасности (факт, нейтрально)

Публичная позиция Mirendil: опасность не в самоулучшающемся ИИ как таковом, а в концентрации доступа у горстки лабораторий; **надзор (oversight)** трактуется как решаемая инженерная задача, а не отдельная научная программа безопасности. Пункты вакансии про guardrails, reliability и observability — практическое воплощение этой трактовки: контроль и прозрачность встроены в обвязку агента.

*Оговорка (нейтрально):* это заявленная инженерная позиция компании. Anthropic и OpenAI, напротив, публично называли рекурсивно самоулучшающийся ИИ (RSI) риском, требующим глобального надзора. Настоящая вики фиксирует обе стороны и не выносит суждения о том, кто прав.
