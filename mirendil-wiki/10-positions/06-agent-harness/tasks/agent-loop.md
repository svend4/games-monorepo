# Архитектура agent loop и интеграция инструментов

[⌂ Вики](../../../README.md) · [Позиции](../../README.md) · [Agent Harness](../README.md) · Agent loop

## Источник (дословно)

> Build and innovate on the agent harness: agent loop architecture, tool integrations, prompt scaffolding, execution environments, and capability primitives

## Что это простыми словами

Модель сама по себе умеет только выдавать текст. Чтобы она стала *агентом* — то есть могла что-то делать в реальном мире (запустить код, прочитать файл, дообучить модель) — вокруг неё строят обвязку. Её сердце — **agent loop (цикл агента)**: модель думает, выбирает инструмент, инструмент выполняется, результат возвращается модели, и цикл повторяется, пока задача не решена. Эта страница — про проектирование самого цикла и про то, как подключать к нему инструменты.

## Что конкретно делает инженер

- Проектирует **архитектуру agent loop (agent loop architecture)** — как чередуются шаги рассуждения (reasoning), вызовы инструментов (tool calls) и обработка их результатов; как решается, когда остановиться.
- Разрабатывает **интеграции инструментов (tool integrations)** — единый способ описать инструмент модели (сигнатуру, аргументы, формат результата) и надёжно исполнить его вызов.
- Строит **промпт-каркас (prompt scaffolding)** — структуру системных подсказок и шаблонов, которая направляет модель, задаёт формат вызова инструментов и удерживает её в рамках задачи.
- Настраивает **окружения исполнения (execution environments)** — изолированные среды (например, sandbox/контейнеры), где безопасно выполняется код и команды агента.
- Проектирует **примитивы возможностей (capability primitives)** — базовые «кирпичики» действий (выполнить код, прочитать/записать файл, запустить job), из которых собираются сложные сценарии.

## Зачем это Mirendil

Продукт Mirendil — модели, экспертные в ИИ-R&D, которые сами ведут исследование. *Аналитическая реконструкция:* именно agent loop превращает такую модель в исследователя-практика — она не просто «советует», а сама запускает эксперименты, читает логи и решает следующий шаг. Чем чище цикл и чем богаче примитивы возможностей, тем ближе система к тезису **self-accelerating AI**, где месяцы ручной работы сжимаются в дни автоматических итераций. Prompt scaffolding и tool integrations также лежат в основе слоя «vibe research» — интерфейса, через который менее технический доменный учёный ставит эксперименты, не программируя обвязку сам.

## Термины

- **Agent loop (цикл агента)** — повторяющийся цикл «рассуждение → вызов инструмента → результат → следующий шаг».
- **Tool integration (интеграция инструмента)** — способ описать модели доступное действие и исполнить его вызов.
- **Prompt scaffolding (промпт-каркас)** — структурированные подсказки/шаблоны, задающие поведение и формат вывода модели.
- **Execution environment (окружение исполнения)** — изолированная среда, где выполняется код агента.
- **Capability primitive (примитив возможности)** — элементарное действие-«кирпичик» для сборки сложных сценариев.
