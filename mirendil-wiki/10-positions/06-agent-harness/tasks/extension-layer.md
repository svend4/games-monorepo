# Слой расширений: модели ↔ внешние инструменты

[⌂ Вики](../../../README.md) · [Позиции](../../README.md) · [Agent Harness](../README.md) · Слой расширений

## Источник (дословно)

> Own the extension layer between our models and external tools, APIs, and environments — making it fast to bring new capabilities online

## Что это простыми словами

Чтобы агент умел что-то новое — вызвать внешний сервис, обратиться к чужому API, работать в новом окружении — эту возможность надо ему «подключить». **Слой расширений (extension layer)** — это интерфейс между моделями Mirendil и внешним миром: инструментами, API и средами. Задача — сделать так, чтобы **новую возможность (capability)** можно было включить быстро, без переписывания всей обвязки.

## Что конкретно делает инженер

- Владеет **слоем расширений (extension layer)** — единой границей между моделями и внешними **инструментами, API и окружениями (external tools, APIs, environments)**.
- Проектирует так, чтобы **новые возможности (capabilities)** подключались быстро — стандартный контракт для нового инструмента, минимум разовой интеграционной работы.
- Реализует адаптеры к внешним **API** — аутентификация, обработка ошибок, ограничение частоты запросов (rate limiting), приведение форматов.
- Обеспечивает изоляцию и безопасность интеграций — чтобы подключение внешнего сервиса не подрывало надёжность и защиту исполнения.
- Поддерживает согласованность контрактов инструментов с agent loop и слоем оркестрации, чтобы новый инструмент сразу работал у всех агентов.

## Зачем это Mirendil

Ценность автоматического исследователя тем выше, чем шире набор доступных ему действий. *Аналитическая реконструкция:* скорость подключения новых возможностей — прямой множитель тезиса **демократизации фронтир-R&D**: чтобы доменный учёный (drug discovery, химия, биология, робототехника, материаловедение) через слой «vibe research» ставил эксперименты в своей области, обвязка должна уметь быстро подключать инструменты именно его домена. Extension layer — это то, через что специфика каждой научной области входит в общую агентную платформу без переписывания ядра.

## Термины

- **Extension layer (слой расширений)** — интерфейс между моделями и внешними инструментами/API/средами.
- **Capability (возможность)** — конкретное действие, которое агент может выполнить через подключённый инструмент.
- **API (интерфейс программирования приложений)** — контракт, по которому программы обращаются к внешнему сервису.
- **Rate limiting (ограничение частоты)** — контроль числа запросов к внешнему сервису за единицу времени.
