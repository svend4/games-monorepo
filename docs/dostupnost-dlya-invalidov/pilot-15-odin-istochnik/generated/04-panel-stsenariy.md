# Помощь по хозяйству — сценарий панели персонала

> Сгенерировано из того же источника (представление 4 из 4). Это НЕ экран жизненно важных потребностей из `../03-pult-upravleniya-uhod.md` (тот — про мгновенные физические нужды резидента), а его родственник — канбан-доска для соцработника, ведущего заявки на услуги. Визуальный язык карточек — тот же, что в `../demo/pult-nuzhd-demo.html` (`.queue-item`, светофорная заливка по времени ожидания).

## Колонки доски

Новая заявка → На проверке → Одобрено → Активно → Возражение (Widerspruch)

## Пример карточки в колонке «На проверке»

```
┌ 🧹 Помощь по хозяйству ──────────────┐
│ Клиент: (демо) Иванова А.П.            │
│ Шаг: 3 из 5 — Пройти простую проверку — какая помощь нужна
│ Ожидаемая стоимость: 20–55 € за одно посещение │
│ Ожидание: 3 дня  [светофор: 🟡]         │
└─────────────────────────────────────────┘
```

## Правило светофора (как в демо-панели)

- 🟢 зелёный — заявка младше 5 рабочих дней;
- 🟡 жёлтый — от 5 до 10 рабочих дней;
- 🔴 красный — больше 10 рабочих дней без движения (повод позвонить в кассу).

Пороговые значения — не минуты, как в демо-панели ухода, а рабочие дни, но JS-логика `elapsedClass()` из `pult-nuzhd-demo.html` подходит без переписывания — меняются только числа порогов.
